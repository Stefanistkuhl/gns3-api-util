## gns3util cluster-control users revoke-token

Revoke a JWT token

### Synopsis

Revoke a token by pasting its raw JWT string.
The JTI is extracted from the token payload automatically — no manual decoding
needed. Once revoked the token is rejected on all future requests even if it
has not yet expired.

```
gns3util cluster-control users revoke-token <jwt> [flags]
```
